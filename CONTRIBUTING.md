# Contributing

For setup, submodules and daily commands, see [Getting started](docs/getting-started.md). Use pnpm and preserve the lockfile.

- Naming, layering and localization: [Engineering conventions](docs/engineering-conventions.md).
- Choose validation by risk: [Testing strategy](docs/testing-strategy.md). Conversation changes follow the [maintenance guide](docs/conversation/dual-track/conversation-maintenance-guide.md).
- Submodules and builds: [Micro-app runbook](docs/micro-apps-runbook.md).
- Test deployment: [Deployment runbook](docs/deploy-sync-test-runbook.md).

Use conventional commits. The commit hook formats staged files. Describe behavior changes, validation and remaining limitations in the PR; use [REVIEW.md](REVIEW.md) for review.
