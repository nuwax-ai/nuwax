## 根因与修复

原会话页在 inactive 时移除终端节点并重置挂载状态，文件预览/独立预览切换也会卸载终端父面板；控制台 visible 改为 false 时，原自动连接 Effect 默认会断连。整页缓存还会按会话任务终态和宽限时间淘汰页面，这与用户手动启动的终端命令生命周期不一致。

新增应用级 ConversationTerminalHost，通过门户容器保留每个会话的工作区。页面仅负责挂接/分离容器；隐藏时清除页面回调，已连终端继续接收输出及保活。每个终端标签沿用现有控制台和独立 ttyd WebSocket，切换只改变可见性；显式关闭、删除会话、退出登录或改变沙箱/业务地址才释放相应资源。其他开发/线上控制台的原接口保持兼容。
