## 0. 前置准备

1. 确认仓库分支：`git log --oneline -1` 应为 `feat/conversation-ux-m1` 头部或更新（含渲染线全部提交）。
2. 启动 dev server：`npm run dev`，端口看启动日志（3000 被占会自动跳 3001，下文以 3000 为例）。
3. 浏览器打开 `http://localhost:3000/mock-chat`（无需登录）。
4. **语言检查**：页面文案应为简体中文。若显示英文，是登录真实账号后语言被同步为账号偏好所致——点右上角语言切换回「简体中文」即可（自动化 e2e 已在启动时钉死 zh-CN 并清登录残留）。
5. **URL 参数速查**（也可页面下拉+播放操作，URL 用于直达）：

| 参数 | 作用 | 建议值 |
| --- | --- | --- |
| `?scenario=ID` | 直达场景 | 见各节 |
| `&speed=N` | 回放速度（事件间隔 = delayMs × N） | 看流式过程用 **3**；快速到终态用 0.05 |
| `&autoplay=1` | 打开即自动播放（否则只装载需手点播放） | 必带 |
| `&conversationRuntime=0/1` | 双轨切换（0=legacy 旧线，1=runtime 新线） | 默认 0 |

6. 页面控件：场景下拉选择、Speed 滑档、「播放场景 / 仅重置」按钮；每换一次场景建议点一次「仅重置」再播放，避免状态残留。

## 1. 思考按流式位置内联渲染

**场景**：`LONG_TASK_INTERLEAVED` · 直达：`/mock-chat?scenario=LONG_TASK_INTERLEAVED&speed=3&autoplay=1`

**步骤**：

1. 打开上述 URL，观察播放过程（约 15 秒）。
2. 播放中观察助手消息内的思考块形态与位置。
3. 播放结束后看终态。
4. 点击第一个「已思考」摘要行，再点一次收起。
5. 按 F5 刷新页面。

**验收点**：

- [ ] 播放中：思考中以**单行滚动条带**展示（市面通行形态）——左侧「正在思考 · Ns」计时递增，思考文字在一行内快速流动播放（连续缓动 + 渐变扫光动效，无多行预览）
- [ ] 后续工具调用出现后，该思考块**自动平滑收起**为「已思考」摘要行
- [ ] 两条消息里共有 **2 个思考块**（两轮思考各自成块），位于各自真实发生的时序位置（工具调用之间），而非消息顶部聚合
- [ ] 终态：所有思考块与工具组均为收起的摘要行，页面不长条滚动
- [ ] 点击摘要行可展开看到思考原文，再点收起；**手动展开不受自动折叠覆盖**
- [ ] 刷新后：历史消息仍显示 2 个「已思考」摘要行（持久化回放正常）
- [ ] 全程**不出现**旧版顶部思考区（「已思考(展开箭头)」的通栏头部）

## 2. 折叠效果全景（汇总演示，5 分钟看完整个需求）

**场景**：`COLLAPSE_SHOWCASE` · 直达：`/mock-chat?scenario=COLLAPSE_SHOWCASE&speed=3&autoplay=1`

**步骤**：

1. 打开上述 URL 观看全程（约 20 秒：4 轮思考 × 2 个工具组 × 1 次终端执行 × 长正文）。
2. 观察每一类内容「出现 → 被超越 → 收起」的时序。
3. 结束后逐一点击每种摘要行（已思考 / 工具调用 / 终端卡）回看。

**验收点**：

- [ ] 思考块：每轮思考中以单行条带流动播放（正在思考 · Ns），到下一内容出现即收起；终态共 4 个「已思考」摘要行
- [ ] 工具组：每组执行时展开可见，被后续思考/正文超越后收成「工具调用 2 项」；终态共 2 组
- [ ] 终端卡：收起为 `$ echo demo-$((41+1))` 一行 + 绿色 `exit 0` 徽标 + 耗时；**未展开时看不到输出全文**
- [ ] 点击终端卡标题：展开等宽输出块（含 `demo-42` 与 `real 0m0.01s` 标记行），限高滚动
- [ ] 终态整条助手消息只剩一列摘要行 + 末尾正文两段

## 3. 终端输出渲染（P0-1）

**场景**：`TERMINAL_OUTPUT` · 直达：`/mock-chat?scenario=TERMINAL_OUTPUT&speed=3&autoplay=1`

**步骤**：

2. 结束后核对三张终端卡（install / test / retest）的徽标。

4. hover 任一终端卡右侧，确认「查看详情」弹窗仍可用。

**验收点**：

- [ ] 执行中（EXECUTING）：命令行摘要下方显示**尾部输出预览**（最近几行，等宽字体），随输出自动滚底
- [ ] 结束后收为摘要行：`$ npm install` / `$ npm test` 命令 + 退出码徽标 + 耗时
- [ ] `exit 0` 为绿色、`exit 1`（失败那次）为红色
- [ ] 点击展开：全量输出等宽块、暗底、限高滚动；未展开时全文不可见
- [ ] 「查看详情」JSON 弹窗正常（原有能力不回归）

## 8. 会话密度三档（P1-6，交互线）

**场景**：任选 `COLLAPSE_SHOWCASE` 或 `LONG_TASK_INTERLEAVED` · 入口：输入框上方工具条的密度下拉（compact / normal / detailed）

**步骤**：

1. speed=0.05 播放到终态，密度保持默认（normal），记录折叠形态（同 §1/§2 验收点）。
2. 切换为 **detailed**，点「仅重置」后重放同一场景。
3. 切换为 **compact**，重置重放。
4. F5 刷新页面，确认密度选择保持。

**验收点**：

- [ ] normal（默认）：被超越的工具组/思考块自动收起，尾部活动内容展开（即 §1/§2 行为）
- [ ] detailed：过程内容**恒展开**，「被超越自动收起」禁用（无收起动画）
- [ ] compact：流式进行中工具组也**默认收起**（只看状态行不看过程）
- [ ] 三档切换即时生效，无需刷新
- [ ] 刷新后密度偏好保持（localStorage 持久化）

## 14. 已知差异（不计入验收失败）

| 现象 | 原因 | 参考 |
| --- | --- | --- |
| runtime 轨（`conversationRuntime=1`）干预审批卡不渲染 | runtime 干预桥接另行立项 | e2e KNOWN_ISSUES |
| runtime 轨 OpenUI inline 不渲染（OPENUI_RENDER / OPENUI_INTERACTIVE） | 消息投影未接 OpenUI applier | 同上 |
| 全量 vitest 有 3 个基线既有失败（replaceMathBracket ×2、Event 用例） | 基线问题，与本分支无关 | `nuwax-test-baseline-quirks` |
| 真实链路无终端专属卡 | 后端协议未接入 | 计划文档「后端确认清单」① |
| 登录后 mock 页文案变英文 | 账号语言偏好被 `syncLangFromUserInfo` 同步 | §0 步骤 4；e2e 已钉死 zh-CN |
| md 预览标题字号/引用块/分割线/段落间距未对齐 | ux-m1 仅对齐代码块/表格/列表三块 | `mobile-parity-checklist.md` §J |

> runtime 轨此前的桥接死循环与终态 text 覆盖问题**已修复**，详见 [fixes/runtime-bridge-loop-and-terminal-text-overwrite-fix.md](./fixes/runtime-bridge-loop-and-terminal-text-overwrite-fix.md)。
