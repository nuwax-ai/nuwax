> 📚 文档总入口:[conversation-docs-index.md](./conversation-docs-index.md) 提测基线:commit `cf5ab966c`(2026-08-17,分支 `refactor/conversation-dual-track`)。读者:**测试同学**。开发/维护视角的行为底稿见 [conversation-business-logic-checklist.md](./conversation-business-logic-checklist.md)(两文共用一套条目 ID,如 `C8`、`D8`,报缺陷请引用 ID)。用法:先读 §1 改动点、§2 影响范围定测试广度;按 §3 策略分层执行 §4 用例;§5 是不用报缺陷的已知边界。

## 1. 改动点(这次提测改了什么)

背景一句话:会话模块做了**双轨重构**——在不动旧实现的前提下,新增了一套会话运行时(新线),通过开关整体切换,目标是行为与旧线完全一致且随时可回退;期间还合入了多项修复。**测试的核心命题:新线开关打开后,一切会话行为与旧线无差别。**

| # | 改动点 | 内容概要 | 用户可见变化 / 测试关注 | 对应用例 |
| --- | --- | --- | --- | --- |
| 1 | 会话运行时新线(runtime) | 消息状态仓、SSE 连接编排、恢复编排、副作用分发全新实现;五入口接线,`?conversationRuntime=1` 启用 | **应当无感**——所有会话行为与旧线一致;任何差异即缺陷 | 全部用例(每条两遍,见 §2.4) |
| 2 | 双线开关(flag) | URL 参数 > localStorage > 默认旧线;可随时切回 | 切换后刷新页面生效;默认(不带参数)仍是旧线 | L1–L3 |
| 3 | 新线行为收口(R6) | suggest 防抖、会话标题只更一次、taskStatus 统一写回、任务冲突弹窗、预览隔离语义、加载更多、审批回执 | 建议问题时机、侧栏标题、冲突提示、预览 Tab 独立性 | B3/C5–C7/N3–N5 |
| 4 | **收尾闪烁修复** | 轮询加「协议终态」门禁、丢弃未落库快照、DOM 身份键改造 | 长回答/多轮/切后台后**收尾不闪烁、不重复、不跳变** | C8 专项十项(P0) |
| 5 | 轮询竞态修复 | 发送瞬间作废在途旧快照 | 轮询间隙快速发消息不被冲掉、无 canceled 报错 | E3 |
| 6 | 错误终态修复 | 出错/断网立即落失败终态 | 出错后停止按钮消失、输入恢复、侧栏不卡「执行中」 | C4 |
| 7 | 恢复节律强化 | 刷新恢复加冷却/退避/等历史落库/去重 | 刷新续播更稳:不重复气泡、不漏用户消息、不闪烁 | D 域全部 |
| 8 | 审批队列与 MCP Ask 增强 | Dock 堆叠 FIFO、恢复重放幂等、Ask 表单文件上传/多步向导 | 审批堆叠只处理最早一张;刷新后不重现已批卡;表单可传文件 | G/H 域 |
| 9 | 消息队列演进 | 「立即发送」不再先停止、防双发看门狗、参数快照、24h 持久化 | 流式中排队消息可靠逐条发出、技能/模型参数不丢 | F 域 |
| 10 | agentMode 缓存升级 | 模式记忆改为**按智能体**维度(兼容旧缓存) | 不同智能体各自记住 yolo/ask;跨标签页同步 | I 域 |

## 2. 影响范围

### 2.1 功能范围

会话域全量(13 个能力域):发送与乐观上屏 / 流式渲染 / 停止与终态 / 刷新恢复 / 状态轮询 / 消息队列 / 权限审批 / MCP Ask / 模式切换 / 历史与加载更多 / 滚动 / 多页签 / TaskAgent 与预览隔离。**改动集中在「会话怎么跑」,不改变消息展示样式与文案。**

### 2.2 入口范围(每个入口都要覆盖)

| 入口 | 地址(测试环境) | 验证重点 |
| --- | --- | --- |
| 主 Chat 会话 | `/home/chat/{conversationId}/{agentId}`(可靠会话:女娲 3994) | 全量用例主战场 |
| TaskAgent 会话 | 同上(TaskAgent 1596) | 思考流、文件树/终端/电脑联动、收尾文件打开(❗ 见 §5.1) |
| 智能体编排页·预览调试 Tab | `/space/57/agent/3994` | 与主会话数据隔离、主会话执行中时输入禁用 |
| 会话面板(ConversationAgent 页内) | ConversationAgent 页 | 同预览 Tab 隔离语义 |
| 插件会话(PluginChatSession) | 插件工具页 | runtime 线基本收发 |
| 技能会话(SkillDetailsConversation) | 技能详情页 | 基本收发(复用主 Chat 内核) |

**不受影响**:AppDev Web IDE、非会话类页面、消息 UI 样式。

### 2.3 数据与兼容

- localStorage 键:`conversation_runtime_enabled`(新,开关粘性)、`nuwax_agent_mode_cache`(结构升级,自动兼容旧值)、`msg_queue:{会话id}`(队列持久化)。用旧版本升级上来的浏览器要回归一次。
- 后端接口无变更;无需后端配合项(除 §5 已知边界中的落库时序)。

### 2.4 双线维度(本轮回归的特殊要求)

**每条用例原则上跑两遍**:旧线直接打开页面(默认);新线同地址加 `?conversationRuntime=1` 后刷新。两条线结果必须一致——**不一致本身就是缺陷**(报缺陷注明线别)。

- 临时切新线:URL 加 `?conversationRuntime=1`(已有 `?` 则用 `&`)
- 用户级粘性:Console 执行 `localStorage.setItem('conversation_runtime_enabled','1')` 后刷新;清除 `localStorage.removeItem('conversation_runtime_enabled')`
- 强制回旧线:URL 加 `?conversationRuntime=0`

## 3. 回归策略

### 3.1 环境与前置

1. dev server:`npm run dev`(默认 `http://localhost:3000`,或按提测环境)。
2. 登录态:测试账号已登录(首页能看到「最近使用」)。
3. 测试会话:女娲 3994(通用收发)、TaskAgent 1596(工作区)、预览 Tab `/space/57/agent/3994`。审批/Ask 用例使用团队既有的审批测试智能体;若无,找开发提供触发钩子。
4. 排障工具(可选):Console 过滤 `[DEBUG-chat-poll-before-final]` 观察 C8 门禁;`[ConversationStreamResume]` 观察恢复/轮询日志。

### 3.2 分层

| 层 | 定义 | 出口要求 |
| --- | --- | --- |
| **P0 冒烟** | 主链路,任一不过即阻塞提测 | 100% 通过 |
| **P1 核心** | 竞态、恢复、队列、审批、多页签、隔离入口 | ≥95% 通过且无阻塞级缺陷 |
| **P2 边缘** | 极端与兼容(损坏数据、超时、越界操作、开关关闭) | 记录结果,不阻塞 |

### 3.3 自动化已覆盖的部分(不必人工重复)

提测前开发已跑:`npm run test:conversation`(33 文件 292 条合同)+ `npm run e2e:conversation`(8 场景浏览器验收)。**人工回归聚焦自动化测不到的**:双线一致性的肉眼判定、多页签、弱网/断网、慢落库时序、视觉闪烁、复杂表单交互、跨标签同步。内部实现类条目(如 digest 对比、store 行为)不在人工范围。

### 3.4 缺陷记录约定

报缺陷请附:**用例 ID + 线别(legacy/runtime)+ URL + 会话 id + 操作步骤 + Console 截图**(含 `[ConversationStreamResume]`/`[DEBUG-chat-poll-before-final]` 日志更佳)。

## 5. 已知问题与边界(这些不用报缺陷,按标注处理)

1. **❗ 新线 TaskAgent 文件链疑似缺口(重点)**:runtime 线上「任务完成 → 文件树/Git/自动打开文件」与「远程桌面、工具调用时文件树刷新」**可能不触发**(开发侧核查:相关副作用在新线缺分发点,见清单 L6)。**验证 N1 时按实际表现记录**:若 runtime 线确实不触发,属已知缺口走缺陷流程但标注「疑似双轨迁移遗漏」,由开发定性;旧线必须正常。
2. **TaskAgent 4042 会话**:自动化工具在其中的编辑器输入不生效——是测试工具限制,人工操作正常;人工回归不受影响,自动化请用 1596。
3. **收尾瞬间后端落库时序**:依赖「FINAL_RESULT 之后助手消息必可查询」的契约;若后端改时序出现的闪烁需后端一起看,先记录时序信息。
4. **诊断日志**:开发环境 Console 有 `[DEBUG-chat-poll-before-final]` 等调试日志属临时设施,非缺陷。
5. **Ask 表单慢落库补偿(旧线 B11)**:依赖延迟补读,新线该链路属 §5.1 同类待定性项。
6. 队列隔天过期、存储损坏降级等 P2 项允许结果记录为「符合设计」即可。
