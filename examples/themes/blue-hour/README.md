# 澄蓝 · Blue Hour

蓝白浅色与蓝灰暗黑主题，支持跟随系统。

安装：在支持主题插件的 Nuwax 版本中打开设置 → 主题 → 导入和应用，选择 blue-hour-1.0.0.zip。现有正式客户端若尚无此入口，需要包含 theme-plugins 改动的版本。

本地修改：桌面端可关联解压后的目录，修改 tokens/_.json 或 styles/_.css，校验通过后自动更新。Web 修改后重新导入，同 ID 确认覆盖。

包不含 JavaScript、不修改业务布局。消息和资料库通过宿主 overlay 接入，上游源码不变。字体使用系统字体。

preview.png 为同一份主题通过生产主题加载器渲染的组件预览，不代表完整客户端验收。

恢复默认：设置 → 主题 → 恢复默认。主题文件有错误时保留最近有效版本。
