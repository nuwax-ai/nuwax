# 规格：PC 商业授权入口管控

- 对应 intent：`plans/20261008-pc-commercial-license-intent.md`
- 状态：按用户已接受方案实施

## 数据与分层

`TenantConfigInfo` 增加两个可选 boolean 字段，租户接口不变。纯策略位于 utils，React Hook 消费现有租户配置模型；组件不得各自转换字符串、数字或回退到旧 `commercialEdition`。字段缺失视为未授权。

## 页面行为

- 创建与筛选选项隐藏 AgentFlow、AgentGroup；配置变化导致筛选不可见时回到“全部”，不筛除已有智能体数据。
- 两种侧栏隐藏项目入口，不挂载隐藏的项目面板；经典布局缓存项目 Tab 时回到任务。工作空间项目&应用按菜单 code 或对应列表路由识别，不限制直达页。
- 隐藏知识图谱与智能分段；当前图谱视图回到文档，智能分段选择回到自动分段。
- 新增推荐子类型仅允许 Chat；授权变化时重置选中项，提交时再次检查。编辑子类型保持原值且不可修改。

## work 授权入口

主站依据已配置的伙伴/资料库菜单及既有微应用路由登记识别目标；覆盖 `/repo`、`/repo-entry`、`/instant-message`、`/message-entry` 与旧 iframe 包装。对应菜单保留，未授权时内容区展示统一提示。门控发生在路由页面/iframe/持久微应用实例挂载之前，不能仅依赖菜单点击。授权撤销时释放已挂载实例。其他应用的保活行为不受影响。

## 验收与协作

覆盖严格布尔、独立组合、配置变化、两种侧栏、新增/编辑推荐及各路由入口。默认菜单调整由后端负责，独立应用地址兜底由应用维护同事负责。新增提示接入五语言字典。前端不新增签名验证或 License provider 接口。
