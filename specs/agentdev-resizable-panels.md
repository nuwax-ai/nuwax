# 规格：agent-dev 面板宽度可调整

- 对应 intent：`plans/20260928-agentdev-resizable-panels-intent.md`
- 方案依据：现有 AppDevPro / Chat 的 ResizableSplit 已实现拖动、遮罩、保活和宽度偏好。

## 需求基线

保留 16px 圆角、调试内容左右 20px、外部右侧 20px 与输入框底部对齐。分隔条置于开发会话与整个文件树/预览/终端工作区之间。

## 方案设计

- ConversationAgent 复用 ResizableSplit，开发会话最小 430px。
- 右侧最小预留 440px（预览 430px、栏间 padding 与边框）；文件树展开时额外预留既有 280px。
- 分栏容器的最小宽度为两栏最小宽度之和；section 负责横向滚动，避免共享组件在空间不足时按比例放松本页约束。
- 分栏宽度沿用 Chat / AppDevPro 已有偏好读写；不重建会话或终端子树。
- ResizableSplit 同宽度下最小宽度变化也应重新约束位置，修复文件树展开后边界未更新的场景。
- 全屏预览维持既有覆盖视口行为；不添加业务接口或数据字段。

## 异常与失败场景

- 窄窗口：工作区横向滚动，保持面板可用宽度。
- 文件树展开/收起：必要时移动分隔条以满足预览下限，不卸载右侧会话。
- 偏好存储不可用：沿用既有降级逻辑，仅本次页面内调整。

## 测试计划

新增同宽度动态边界回归测试，运行现有分栏保活测试及会话合同测试。在用户 URL 实际验证拖动、最小宽度、文件树展开、窄窗口滚动、内边距和圆角。
