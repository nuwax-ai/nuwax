# 规格：正常正文分隔的过程段折叠

- 对应 intent：plans/20260928-trace-segment-collapse-intent.md
- 状态：实现规格；边界已根据用户截图和现有投影代码核对。

## 需求基线

实现用户要求的流式过程分段收起，保留现有整轮与工具详情折叠能力。

## 方案设计

### 架构落点

在 presentation-v2 增加纯函数 traceSegments：先按原始 nodes 中的 narration 分段，再做渲染偏好过滤。WorkTraceDisclosure 托管段级展开状态，原节点与工具组状态继续由该组件持有。

### 数据与契约

- 每段用首节点 ID 生成稳定键；追加节点不改变键。
- narration 关闭前段。投影将最新正文单独放进 finalAnswer，因此非空 finalAnswer.text 也关闭尾段。
- 活动段只可能是运行轮末尾、未被正文关闭的段。
- 段汇总只统计该段工具/子智能体去重调用数、思考/上下文/已完成交互数；耗时仅采用该段节点可信起止时间，不复用整轮起点。
- 运行中的活动段直接展示。已关闭段默认收起，关闭时清除一次运行期手动展开；关闭后用户再次展开保持选择。
- 终态仍采用原整轮默认收起/展开模式，避免新增额外历史层级；正常 narration 与 OpenUI 产物始终可见。
- 不新增后端接口、持久化设置或 UI 文案，复用现有汇总词条。

### 平台/引擎矩阵

| 行为                   | legacy/runtime | Web/Electron WebView |
| ---------------------- | -------------- | -------------------- |
| 正文关闭段、显示汇总   | 共用投影与展示 | 共用渲染器           |
| 工具、思考详情手动展开 | 原状态托管     | 原回调和偏好         |

## 异常与失败场景

- 无过程节点不生成空段。
- 隐藏节点仍参与原始分段和计数；恢复入口可找回内容。
- 失败摘要及 OpenUI 产物遵循既有能力，OpenUI 不随段详情卸载。
- 耗时数据不完整时不臆造值；每秒计时仍只更新整轮标签。

## 测试计划
