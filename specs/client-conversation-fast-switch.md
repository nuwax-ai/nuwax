# 规格：client-conversation-fast-switch

- 对应 intent：`plans/20260923-client-conversation-fast-switch-intent.md`
- 状态：代码已实现，待真实客户端登录态验收

## 用户可见行为

商业客户端 style3 从运行中的会话切向其他会话或菜单，再返回命中内存实例时，消息、输入、滚动、流式进度、文件/预览/终端及编辑器状态保持；不出现整页加载闪烁。超出上限、主动删除或释放后重新进入，从后端恢复执行和消息状态，草稿与面板偏好按既有契约保留。

## 实例与资源规则

- 实例身份以页面类型、项目与会话 ID 确定；同一会话的不同宿主不得误共享页面实例。
- 最多 5 个整页实例，其中 IDE 工作台最多 2 个。新增实例前优先释放隐藏非运行页，再释放最久未访问的隐藏运行页；当前可见页始终保留。
- 隐藏实例转终态后延迟 60 秒释放；容量不足可提前释放。会话删除立即失效；登出清空整页实例。VNC 保持全局唯一。
- 隐藏页继续处理必要的会话结果，暂停动画、可见性观察和非必要轮询；激活时以最新数据同步画面。

## 技术前置

`conversationInfo`、`chat`、`conversationAgent` 等 Umi model 是全局单例；每个并存页面的读写与卸载清理必须完成实例隔离或有可证明的等价保护后，才能加入整页保活宿主。直接把多个路由页面 `display:none` 常驻不符合本规格。

## 验收

覆盖普通会话、Agent 开发页、全栈 IDE 与菜单互切；验证并发运行、多页上限、终态延迟释放、超限恢复、删除/登出和 VNC 换主。自动化测试与真实客户端登录态验收分别给出结果。

## 当前验证边界

自动化已覆盖实例隔离、热切复用、草稿作用域、路由快照、隐藏副作用及缓存释放。浏览器里的桌面壳预览在业务 iframe 处被本地鉴权重定向到返回 404 的接口，尚无法测量真实客户端多会话切换耗时、峰值内存和隐藏流式更新的 CPU 开销。
