# 规格：page-container-header

- 对应 intent：`plans/20260922-page-container-header-intent.md`
- 状态：技术评审通过（用户已明确要求公共方案并逐页接入）

## 需求基线

以 intent 为准。本期只统一页面级标题栏的响应式排布，不改变标题栏内控件的业务语义。

## 方案设计

### 架构落点

- 在 `src/components/PageContainerHeader/` 新增纯展示公共组件。
- 公共组件提供 `title`、`titleExtra`、`middle`、`actions` 四个插槽：前三者组成左侧可换行内容，`actions` 作为右侧操作组。
- 根容器允许换行；操作组使用自动左外边距和右对齐，使其在首行和新行都贴右。
- 操作组内部也允许换行，避免搜索框和按钮在极窄宽度溢出。
- 页面只保留本页特有宽度、间距和业务状态，删除重复的标题栏 flex 规则。

### 数据与契约

- 无接口、存储和路由契约变化。
- React 属性是唯一新增契约；插槽均为可选 `ReactNode`。

### 平台/引擎矩阵

| 行为点 | Windows/Linux 沉浸客户端 | macOS/浏览器 | 备注 |
| --- | --- | --- | --- |
| 宽屏单行 | 支持 | 支持 | 右侧操作贴右 |
| 窄屏换行 | 支持 | 支持 | 操作组换行后仍贴右 |
| 移动端 | 保持页面现有断点 | 保持页面现有断点 | 不替代移动端专用导航 |

## 异常与失败场景

- 超长标题：左侧区域可收缩，页面可沿用省略或换行策略。
- 单个操作控件宽于容器：公共组件限制子项最大宽度，具体控件仍需页面设置可收缩宽度。
- 无标题或无操作区：对应插槽不渲染，不制造空白容器。
- 特殊绝对定位标题栏：列为例外，必须先解除绝对定位后再接入。

## 测试计划

- 公共组件结构测试：插槽、语义标签、空插槽。
- MCP 页面作为基准：宽视口同一行；Windows 1240 宽操作组自动换行且右对齐。
- 每批接入页面执行相关 Vitest、`git diff --check` 和生产构建。
- Windows 真机至少覆盖工作空间资源页、系统管理页和普通项目页各一类。

## 已否决的备选方案

- 仅在 `SpaceMcpManage` 增加媒体查询：不能解决全仓重复和后续漂移。
- 在 `page-container` 全局扫描并改写任意首个 `header`：DOM 语义不稳定，会误伤详情页和业务内嵌标题。
- 只给操作区 `overflow: hidden`：会隐藏功能，不符合可用性要求。
