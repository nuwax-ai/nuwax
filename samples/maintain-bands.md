# Maintain 监控分带样例

| 带 | 判定（示例） | 人响应 | Agent 行为约定 |
| --- | --- | --- | --- |
| **P0 红** | 错误率 > 1% 持续 5min；p99 > SLO；主干 CI 红 | 立即 page 值班 | **停手**：不开新功能 PR，只做止血（回滚/热修），全程人工指令驱动 |
| **P1 黄** | 告警风暴（同类 > 10/5min）；依赖 CVE 可利用版本 | 4h 内开工单 | 可继续在途工作，但新 PR 必须在描述引用工单号；优先修 P1 再排新功能 |
| **P2 绿** | 配额水位 < 70%；慢查询数缓慢上升 | 进周报 | 正常工作；顺手记录进周报草稿，不单独打断 |

## 指标登记样例（按仓维护）

| 指标          | 数据源   | P0 阈值     | P1 阈值        | P2 记录 |
| ------------- | -------- | ----------- | -------------- | ------- |
| HTTP 5xx 比例 | 网关日志 | > 1% / 5min | > 0.5% / 30min | 周趋势  |
| p99 延迟      | APM      | > SLO×1.5   | > SLO×1.2      | 周趋势  |
| 测试通过率    | CI       | main 红     | 分支红 > 2 次  | 周汇总  |

## Agent 触发词（建议写进 AGENTS.md 维护）

- 「P0 进行中」→ 本会话只接受止血类指令；功能类请求回复"等 P0 关闭"。
- 「P1 工单 #N」→ PR 描述必须带 `Closes #N` 或 `Refs #N`。
- 分带判定永远以监控面板/工单为准，agent 不得自行改带。
