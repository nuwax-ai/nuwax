# A2UI 功能验证提示词

> 在聊天输入框中逐条发送以下提示词，观察右侧面板是否正确渲染 A2UI。每个类别从简单到复杂排列，建议按顺序验证。

---

## 一、基础展示组件

### 1.1 Text + Card（最简验证）

```
展示一张卡片，标题为"Hello World"，副标题为"这是我的第一个 A2UI 界面"。
```

### 1.2 标题层级

```
展示所有文本变体：h1 到 h5 标题、正文 body 和说明文字 caption，每种一行。
```

### 1.3 Icon

```
展示一排常用图标：搜索、添加、删除、编辑、星标、首页、设置、刷新，每个图标下面标注名称。
```

### 1.4 Image

```
展示一张图片，使用 Google 的 favicon：https://www.google.com/s2/favicons?domain=github.com&sz=128，图片下方标注"GitHub Logo"。
```

### 1.5 Divider

```
展示三段文字，每段之间用分割线隔开。三段文字分别是"第一章"、"第二章"、"第三章"。
```

## 二、布局组件

### 2.1 Row 水平排列

```
用 Row 水平排列三个统计卡片，分别显示"已完成 18"、"进行中 6"、"待处理 3"。
```

### 2.2 Column 垂直排列

```
用 Column 垂直排列一个简单的用户信息卡：头像、姓名、邮箱、签名。
```

### 2.3 嵌套布局

```
做一个项目看板，顶部是标题和描述，中间一行三个状态列（待办/进行中/已完成），底部一个操作按钮。
```

---

## 三、表单输入组件

### 3.1 TextField

```
做一个用户注册表单，包含姓名（短文本）、邮箱（短文本）、个人简介（长文本）、密码（ obscured）、年龄（数字）五个字段，以及一个提交按钮。
```

### 3.2 CheckBox

```
做一个服务条款确认页，包含标题、一段条款说明文字、一个"我已阅读并同意"勾选框、一个提交按钮。
```

### 3.3 ChoicePicker

```
做一个偏好设置表单，包含：
- 性别选择（单选：男/女/保密）
- 兴趣标签（多选：技术/设计/产品/运营/市场）
- 一个保存按钮
```

### 3.4 Slider

```
做一个评分面板，包含标题、一个 0-100 的满意度滑块、一个备注文本框、一个提交按钮。
```

### 3.5 DateTimeInput

```
做一个活动创建表单，包含活动名称、活动日期（日期选择器）、活动详情（长文本）、一个创建按钮。
```

### 4.1 Video

展示一个视频播放器，使用示例视频 URL。
```

### 4.2 AudioPlayer

```
展示一个音频播放器。
```

## 五、高级组件

### 5.1 List（动态列表）

```
展示一个任务列表，数据包含 4 条任务，每条显示任务名称、负责人和优先级标签。
提示：使用 data 参数传入任务数组，用 List 的 template 模式渲染。
```

### 5.2 Tabs（标签页）

```
做一个设置面板，包含三个标签页："基本设置"、"安全设置"、"通知设置"。每个标签页有不同的表单字段。
```

### 5.3 Modal（弹窗）

```
做一个页面，包含一个"打开确认框"按钮，点击后弹出模态框，框内有"确认删除？"标题和"取消"/"确认"两个按钮。
```

## 六、综合场景

### 6.1 完整表单

```
做一个完整的客户信息录入表单，包含：
- 标题"新增客户"
- 客户名称、联系电话、邮箱
- 客户等级（单选：VIP/高级/普通）
- 兴趣产品（多选：产品A/产品B/产品C/产品D）
- 合作预算（滑块 0-500万）
- 预计签约日期
- 备注说明
- 提交和重置按钮
```

### 6.2 数据仪表盘

```
做一个销售数据仪表盘，包含：
- 标题"Q3 销售概览"
- 一行四个统计卡片（总销售额、订单数、客单价、退款率）
- 分割线
- 一个筛选条件区域（日期范围、渠道选择）
- 一个"导出报表"按钮
```

### 6.3 员工列表

```
展示一份员工列表，包含姓名、年龄、部门和职位。至少展示 5 位员工。表头用 caption 样式，数据行用 body 样式。
```

## 八、边界场景

### 8.1 最少组件

```
展示一行纯文字"Hello"。
```

### 8.2 复杂嵌套

```
做一个三层嵌套的布局：最外层卡片 → 中间层 Row（左右分栏）→ 左栏是用户列表，右栏是详情表单。

## 验证检查项

每条提示词验证时，关注以下检查点：

| 检查项            | 说明                                   |
| ----------------- | -------------------------------------- |
| ✅ 右侧面板出现   | A2UI 面板自动展开                      |
| ✅ 组件正确渲染   | 组件类型、文字、样式与预期一致         |
| ✅ 表单可交互     | 输入框可输入、选择器可切换、滑块可拖动 |
| ✅ 修改生效       | 修改提示词后 UI 自动更新               |
| ✅ 无报错         | 控制台无红色错误                       |
| ✅ 组件不闪烁     | 不会反复重建                           |
| ✅ surfaceId 一致 | 修改同一面板时不会创建新 Surface       |
