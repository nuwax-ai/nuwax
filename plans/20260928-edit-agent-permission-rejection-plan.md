# 实施计划：智能体编排页权限错误回归修复

- 对应问题：`/space/752/agent/3937` 加载后出现 `Unhandled Rejection (BizError): 无此资源权限`。
- 状态：已完成；本次为既有功能缺陷修复，验证限制见下。

## 已确认原因

- 首次进入页面，`GET /api/agent/3937` 成功。
- Tiptap 同步编辑状态的 `setEditable` 默认发出 `update` 事件；提示词序列化后末尾增加换行，触发了非用户操作的自动保存。
- `POST /api/agent/config/update` 返回业务码 `4033`，`handleChangeAgent` 的 `runAsync` 拒绝未被捕获，触发开发环境全屏错误。
