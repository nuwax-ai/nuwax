# Bug 2459 主题配置菜单隐藏计划

## 目标

- 系统管理 → 系统配置不再展示“主题配置”菜单。
- 保留 `/system/config/theme` 路由与页面，避免历史直链和内部主题能力被破坏。
- 同时覆盖路由生成菜单与经典布局的 `SYSTEM_MANAGE_LIST`。

## 改动

1. 给主题配置路由增加 `hideInMenu: true`。
2. 从经典系统管理菜单常量中移除 `Theme_Config` 项。
3. 对后端下发的菜单权限树增加“仅展示过滤”，权限集合仍按原树计算。
4. 添加递归过滤回归测试，运行构建并在登录态真实页面复验菜单不可见。

## 非目标

- 不删除主题页面、主题服务或主题配置 API。
- 不改变普通用户已有的明暗色/品牌主题行为。
