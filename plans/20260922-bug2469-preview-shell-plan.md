# #2469 文件预览全屏避让

工单截图为 Windows 商业客户端：全屏文件预览标题与宿主菜单/窗口按钮重叠。

当前 ConversationAgent 外层已有 immersive-shell-fullscreen 标记，但内层真实 fixed 文件预览及 Chat 公共预览未消费统一避让样式，仍 top:0 / 100vh。仅修外层不约束内层 fixed 元素。

1. 在两个真实全屏预览根挂已有稳定类，不另起宿主判断和尺寸来源。
2. 统一避让层覆盖公共全屏根，同时保留旧外层的高特异性规则；内部高度跟随外盒，避免避让后底部溢出。
3. 组件回归覆盖两个入口全屏/非全屏；登录浏览器实际点全屏，使用明确标记的 Windows 壳变量模拟验证几何。模拟不等于 Windows 安装包验收。
4. 保留浏览器无壳时全视口、退出全屏回到面板的行为；不改动客户端其他 WIP。
