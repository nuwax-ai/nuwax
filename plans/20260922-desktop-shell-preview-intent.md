# 桌面壳浏览器预览器 Intent

## 背景

桌面端页面同时服务 macOS、Windows 与 Linux。当前沉浸式标题栏、二级菜单和 `page-container` 的避让只能在真实客户端中观察，窄窗口问题往往要经历构建、替换资源、重启客户端和截图，反馈周期过长。

## 目标

- 在本地开发浏览器中切换 macOS / Windows / Linux 沉浸式主窗口语义。
- 让被预览页面走现有 `hostBridge` 平台判断和避让逻辑，不维护第二套假样式。
- 以真实 iframe 视口验证媒体查询和 flex/grid 布局，提供客户端最小尺寸 `1200×720` 以及常用尺寸。
- 显示轻量原生标题栏示意，能直观看到页面是否侵入宿主占用区。

## 非目标

- 不模拟文件系统、更新、窗口拖拽等原生能力。
- 不替代最终安装包抽查；真实客户端仍负责确认字体、缩放和系统合成差异。
- 不在生产环境开放调试入口或查询参数覆盖。

## 验收

1. 开发环境可打开 `/desktop-shell-preview`。
2. 可选择三个桌面平台、目标业务路径和至少三个视口预设。
3. `1200×720` 预设与客户端最小窗口尺寸一致。
4. Windows/Linux 预览命中 frameless 避让，macOS 命中 mac 分支。
5. 预览 iframe 与普通浏览器页面隔离，关闭预览参数后业务行为不变。
