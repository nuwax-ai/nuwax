# 计划：补齐本机文件与工作目录路线

## 目标与决定

- 首页新建任务、统一输入框、创建普通项目共用工作目录选择器：所选电脑与宿主本机身份一致且具备目录选择能力时，使用现有系统目录选择桥；浏览器、其他电脑、关闭能力或旧桥仍使用后端目录弹窗。
- 本机选择取消或失败不转后端；关闭、切换电脑、登出后的迟到结果不能写入新任务。原生目录选择串行，避免重复对话框。
- 一并排查 Windows PDF 卡片点击报 `invalid-argument`、文件树为空的问题。优先复现可空会话字段和外部路径进入本机桥的契约问题，不通过捕获错误后重试后端掩盖故障。
- 只修改本 PC Web 工作区，保留现有微应用脚本改动；上传、ZIP 导入和 Git 未提供对应宿主桥，保持原接口。

## 实施与验证

- 在 client-shell 收口本机目录选择与身份校验，共用组件接入，避免三个入口各自实现判断。
- 复用并补充文件域回归，覆盖 Mac/Windows 路径、可空字段、本机/远端/无桥、失败不回退、切换及取消。
- 运行相关 Vitest、会话保护网、架构检查及变更路径类型检查。真实安装包与线上前端生效分别验证，不把 mock 桥测试当作实包通过。
