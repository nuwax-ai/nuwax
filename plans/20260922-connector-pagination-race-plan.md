# 连接器分页接管：末页与首屏补拉竞态

- 触发证据：批量集成会话合同网 `connectorListView.test.tsx` 首屏+第二页预期 2 发，间歇实得 3 发。
- 已稳定复现：数据 hook 只有 loading 的同步门禁，末页响应后 loadingRef 已复位而 React hasMore=false 尚未提交，旧触底回调仍能发 page3（回归实得页码 `[1,2,3]`）；组件将零高度隐藏容器当成未填满容器自动补拉（隐藏首屏回归预期 1 发、实得 2 发）。原测试在首屏完成后才提供容器几何，加大了与自动补拉的竞争。
- 最小改动：追加请求在数据层同步检查 loading/hasMore；成功、失败、重置同步维护 hasMore ref。组件仅对有实际高度的容器判断首屏补拉，并在容器恢复可见/变高时经 ResizeObserver 重新检查，避免隐藏时跳过后短列表永远无法滚动补拉；测试在首屏返回前设置真实几何。
- 验证：末页响应 microtask→ 旧回调重入必须稳定阻止 page3，零高度不补拉，可见未填满仍补拉，显式触底正常追加；条件重置可重新分页；定向与集成会话合同网。只改 ConnectorListView 内聚路径，不推广到其他列表。
