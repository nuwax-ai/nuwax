# 任务列表状态区与双分组吸顶调整

## 用户要求

- 任务会话行的状态区由左侧移到右侧：静止时在时间前，悬停时在更多按钮前。
- 移除行内归档图标，菜单保留归档；菜单触发后的既有行内确认继续保留。
- 项目、任务标题不再显示数量。
- 滚到任务区域后，项目和任务标题上下同时吸顶，任务不能顶掉项目；点击吸顶的项目标题可快速回到项目列表。
- 补充要求：会话执行中不显示时间，执行结束后恢复显示。

## 实施

1. 调整 `ConversationItem` 尾部布局，将状态与置顶操作移到标题后；时间和更多共用尾部位置，避免标题覆盖操作。
2. 删除常驻归档触发图标，保留菜单、确认取消和接口回调。
3. 将两个分组头放在同一滚动包含块内，项目置顶、任务按项目头高度偏移吸顶；去除标题计数，保留折叠与批量展开行为。
4. 运行侧栏现有状态、同步、菜单和项目测试，检查格式及样式；使用已有 localhost:3000 登录态验证时间/悬停布局、双头吸顶与返回项目。

工作区已有的会话运行时、终端及轮询改动与本任务无关，保留现状。

## 验证记录

- 四个定向测试文件共 25 项通过，覆盖状态优先级、执行中隐藏时间并在结束后恢复、列表同步、分页与项目菜单行为。
- Prettier、两份 Less 的 Stylelint 和 `git diff --check` 通过。行尾最小宽度使用 CSS `calc(...)`，修复了 CSS 变量参与 Less 乘法引起的编译错误。
- 已在 `localhost:3000/home` 的真实登录态页面验证：滚动到任务区后，项目头固定在 y=259、高 36px，任务头固定在 y=295、高 28px，二者同时显示且无标题计数。
- 悬停任务行时，状态/置顶槽在 x=188、更多按钮在 x=216，均为 24px，时间隐藏且没有行内归档图标。
- 更多菜单保留归档；选择归档进入行内确认，Escape 可取消。点击吸顶的项目标题后，滚动位置从 1794 回到 0，项目列表保持展开。
