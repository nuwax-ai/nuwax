# 用户 Token 统计：排名与每日趋势（下一版本）

## 范围与版本

- 在已有平台监控和按用户模型明细上增加用户排名、每日趋势。分支 `codex/user-token-ranking-trend`，PR 指向 `feat-2026.11`，属于下一版本；不在本任务合并、部署或发布。
- 统计页面由 PC Web 和客户端 WebView 复用；不修改客户端发布分支或后端。邀请功能及暂缓的 NW-317、终端持久化不在本次范围。

## 接口和页面契约

- `GET /api/system/bill/resource-stat/user-rank`：服务端按 `totalTokens` 降序排序与分页，使用返回的 `rank` 和 `total`。默认本月到今天，日期提交后才生效；翻页保留已生效条件，查询和重置回第一页。不用当前页排序模拟全局排名，不假定未文档化的排序字段。
- 排名按计费承担方展示总 Token、非缓存输入、缓存输入、输出、调用数、消耗积分。禁用或已删除用户保留历史记录；点击趋势传完整用户 ID 和已生效日期。
- `GET /api/system/bill/resource-stat/user-trend`：必传字符串 `userId`，与日期范围一起查询日列表。手动输入用户及排名钻取均可进入趋势；支持查看总量与三种 Token 分量，并列出每日精确明细。不把积分显示为人民币，不把未返回日期补成零。
- int64 ID 与大整数 Token 在请求响应解析前保留为字符串；图表坐标可近似，提示和表格保留精确值。不能用已舍入的数字定位用户。
- 草稿和已提交条件隔离。切换用户、日期、视图及卸载取消请求，忽略迟到结果；失败独立提示和重试，不冒充零消耗。趋势不依赖旧模型汇总/明细接口成功。
