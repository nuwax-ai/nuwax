# 会话工作过程与最终回答的边界

- 展示规则：中间的过程说明随思考、工具一起折叠，最终回答在折叠区外常显。过程消息计数不包含正文。浏览器汇总按操作次数计数，已结束过程耗时缺失或不足一秒时隐藏耗时，运行中正常计时。
- Todo 去重：live 标签可能保留启动名称，而 processingList 已更新名称与结果。相邻 Plan 与 TodoWrite 的去重使用最新工具信息，与实际待办卡分类保持一致。
- 工具组规则定向恢复到 `270efbe6a6` 之前：连续工具合并，思考单独展示并切断工具组；尾部活动组默认展开，后续正文、思考或新组到来时收起旧活动组，手动选择沿用。普通 live 与 sub 续接共用该规则；回退范围仅限工具组，不回退该提交中的最终回答选择、终态收口或单条过程段规则。
- 验证：过程说明折叠后最终回答仍显示；相邻待办重复消除，实际步骤与进度可继续更新；终态耗时缺失及一秒阈值；会话质量门和真实页面本地数据回放。
