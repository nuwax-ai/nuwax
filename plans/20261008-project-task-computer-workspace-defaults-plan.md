## 实施顺序

1. 补充回归用例，确认目录丢失和默认电脑被重置。
2. 补齐透传并调整首页初始化及选择器配置；每次点击新建任务重新继承项目配置，读取一次最新详情，随后允许用户修改。重复点击同项目保留智能体与输入草稿。
3. 运行相关测试、会话合同网、分层检查和改动路径类型检查。

## 证明成立的测试

- 侧栏和详情新建任务携带项目电脑、目录；首页每次新建任务读取一次最新项目详情。
- 常规项目创建者与参与者均继承默认值；目录或电脑修改后发送当前值。
- 智能体记忆和私人绑定不会覆盖项目默认值；项目内仍可修改电脑及目录。
- 切换电脑清除旧电脑目录；云端不携带个人电脑目录。
- 同项目再次新建任务与切换项目均恢复项目默认值，保留同项目智能体和输入草稿。
- 兼容三种目录字段，云端实际沙箱 ID 映射为选择器哨兵；配置加载期间禁止发送或修改，旧请求晚到不得覆盖新项目。
- 保留项目外私人智能体绑定电脑行为。
