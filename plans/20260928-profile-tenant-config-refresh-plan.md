# 个人姓名保存后刷新租户配置

- 状态：已完成
- 授权范围：按用户要求修复个人姓名修改后 `/api/tenant/config` 未刷新的问题。

## 改动与实施顺序

1. 在账号资料组件中复用 `tenantConfigInfo` 模型的 `runTenantConfig`。
2. 用户名或昵称更新成功后刷新租户配置，更新首页依赖的 `homeSlogan` 及本地缓存；使用请求参数判断字段，覆盖昵称清空。
3. 在现有本地开发服务的登录态页面验证保存请求完成后发起配置查询、首页同步更新，并恢复验收前的个人资料。

## 验证与回退

- 检查昵称修改、用户名保存、昵称清空的配置查询顺序，以及保存失败时不刷新配置。
- 头像保存继续沿用现有用户信息更新路径。
- 执行改动文件格式检查、`git diff --check` 和分层依赖检查。
- 回退方式：撤销账号资料组件的本次刷新调用及模型引用。
