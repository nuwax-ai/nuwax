# 意图：统一 page-container 页面标题栏的响应式布局

- 日期：2026-09-22 　发起人：用户
- 状态：已接受（用户，2026-09-22）

## 问题

`page-container` 内各页面分别实现标题、筛选、搜索和操作按钮的横向布局。窗口变窄或 Windows 客户端侧栏展开时，右侧搜索框和按钮可能被挤出可视区；已有页面即使支持换行，也无法保证换行后的操作区继续右对齐。

## 预期结果

- 所有 `page-container` 页面级标题栏使用同一套布局规则。
- 标题及标题旁筛选保留在左侧；右侧操作区空间不足时自动换行。
- 右侧操作区无论位于首行还是换行后都保持右对齐，内部控件仍可继续换行。
- 宽窗口保持单行，不增加无意义的垂直空白。
- Windows 客户端、macOS 客户端和浏览器共享同一响应式行为。

## 受影响的能力面

- 公共组件层：新增 `PageContainerHeader`。
- 页面层：逐页将页面级标题栏接入公共组件。
- 不涉及接口、权限、路由、数据状态或业务行为变化。

## 约束

- 仅覆盖 `SidebarShell` 的 `page-container` 页面级标题栏。
- 弹窗、Drawer、卡片内标题、会话内部标题、全屏工作台不在本期范围。
- 保留每页现有标题文案、筛选控件、搜索状态和点击行为。
- 接入采用分批清单；每批都必须通过静态检查、相关测试和窄宽视口验收。

## 开放问题

- 无阻塞问题。特殊页面若无法映射到“左侧内容 + 右侧操作”契约，记录为例外并单独评审，不在接入时擅自改变业务结构。
