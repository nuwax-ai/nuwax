# 意图：无感预防旧页面缺样式，并提供可选的界面更新提醒

- 日期：2026-10-09
- 状态：已接受（用户在本会话确认并要求实施）

## 问题

direct 客户端在 PC Web 发版后出现局部样式错乱，普通刷新可以恢复。浏览器共用同一套资源；已确认旧产物保留规则遗漏 Webpack 的 `.chunk.css`，但尚未证明截图仅由该漏洞导致。

## 预期结果

保留窗口内旧页面继续取得完整同版资源，无需用户操作。direct 客户端发现线上页面版本变化时，在客户端更新旁显示可忽略的“界面更新”；只有用户点击时才重新加载。

## 受影响的能力面

PC Web 构建元信息、部署资源保留、客户端适配和顶栏徽标。沿用已有版本文件和桥，不新增后端 API 或 Electron IPC。

## 约束

正常资源继续缓存；保留 3 代。不自动刷新、不弹窗、不清登录状态。gateway、浏览器及旧宿主不展示网页更新徽标。Git hash 不烤入业务 JS。

## 开放问题

无产品待确认项。历史产物回填依赖可读取的历史构建；无法恢复的文件须明确记录，不能用新 CSS 冒充旧哈希。
