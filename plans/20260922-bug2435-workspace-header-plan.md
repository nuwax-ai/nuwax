# 禅道 #2435 工作空间管理页窄窗头部加固计划

## 目标

- 在 Windows 客户端常见的 1240px 窗口下，智能体、网页应用、组件、技能、MCP 管理页的筛选、搜索和创建入口均可见、可操作。
- 保持宽窗单行布局；空间不足时按功能组自然换行，不让按钮溢出视口。

## 现状与根因

- 智能体、网页应用、组件和技能页已经使用可换行的页头布局，Windows 真机复验正常。
- MCP 管理页仍使用三个无收缩约束的普通 flex 子项；标题筛选、分段器、搜索和创建按钮的总宽度超过内容区后，最右侧创建按钮被推到视口外。

## 改动

1. 给 MCP 页头的左、中、右功能组补稳定类名和显式的 flex 收缩/换行约束。
2. 搜索框在窄窗允许收缩但保留最小可用宽度，创建按钮不收缩。
3. 宽窗继续保持单行；窄窗只在功能组边界换行。

## 验证

- 触达路径类型检查/生产构建无新增错误。
- Windows 真机 1240px 复验 MCP 页：分段器、搜索框、创建按钮完整可见。
- 回归其余四页，确认既有页头布局不受影响。
