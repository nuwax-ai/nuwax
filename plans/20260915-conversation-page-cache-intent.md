# 意图：会话页面缓存统一管理

- 日期：2026-09-15
- 状态：已实现（用户于当前会话确认，待登录态 E2E 验收）

## 问题

会话切换会清空右侧面板和终端状态；面板、页面实例与输入草稿分别维护，无法统一观察创建、更新、淘汰和失效过程，也缺少缓存上限。

## 预期结果

- 会话维度恢复右侧面板最后视图和输入草稿。
- 同一次浏览最多缓存 5 个会话工作区，新增实例淘汰最久未使用的旧实例。
- 云端 VNC 全局唯一，会话只记录是否显示。
- 开发环境可查看缓存条目、LRU 顺序、资源状态和草稿摘要，并可手动失效。

## 受影响的能力面

Chat 会话页、右侧文件/终端/页面预览、云端电脑展示、ChatInputUnified 草稿缓存和会话调试入口。

## 约束

- resize 交互样式保持现状。
- 草稿正文不得出现在调试信息或日志中。
- 会话路径改动必须通过 `npm run test:conversation`，合入前补 E2E。
- VNC 只允许一个真实 iframe/连接实例。

## 开放问题

无；缓存范围、上限和 VNC 语义均已确认。
