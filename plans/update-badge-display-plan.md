# 更新入口展示优化

## 已确认范围

- 直接在 `/Users/apple/workspace/nuwax` 修改，保留其他已有改动。
- Nuwax 客户端：客户端版本更新优先于网页更新，仅显示一个可用更新入口；下载、安装和有目标版本的重试期间维持客户端优先。
- 浏览器：启用现有网页版本检查，只显示网页更新入口。Nuwax 客户端仍仅 direct 启用，loopback/gateway 不检查、不展示；其他桌面宿主保持原规则。
- 更新入口统一显示“更新”。网页入口沿用客户端更新胶囊及悬停卡片交互；按用户追加要求，对比当前 / 最新的版本号、gitHash、构建时间，不展示更新日志。
- 最新信息读取 version.json 的 version/gitHash/buildAt；当前版本与构建时间固定读取已加载 HTML 标记，旧页面缺少时间时显示“—”。构建追加同一份 buildAt 的 HTML 标记，业务 JS 不注入构建值。
- 保留现有构建 hash、缓存保留、轮询、并发、失败处理和手动刷新机制，不自动刷新或清登录状态。

## 实施

1. 调整网页版本检查宿主门禁并补浏览器覆盖。
2. 网页徽标订阅现有客户端更新状态，处理优先级、统一文案和悬停卡片；补充构建时间标记及版本信息展示。
3. 更新 A/B 夹具，执行相关组件与服务测试、lint 和浏览器/客户端夹具验收。

## 验证

- 客户端更新与网页更新同时出现时，客户端入口优先；客户端更新撤销后恢复网页入口。
- 下载、待安装和带目标版本的失败重试保持优先；没有目标版本的普通检查失败不遮住网页更新。
- 浏览器无需宿主桥即可检查，展示“更新”；gateway 与不支持的桌面宿主仍不检查。
- 网页悬停卡片准确对比 version/gitHash/buildAt，旧标记缺失及非法附加字段安全展示；没有更新日志，两个点击入口均只手动刷新。
- 订阅卸载、StrictMode、隐藏/回前台与轮询清理仍正确。
