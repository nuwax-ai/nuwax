# 需求说明：推荐重复添加与提示词维护

## 背景和目标

用户要求移除推荐管理的重复添加限制，在对话框智能体推荐新增、编辑时维护多个提示词，并检查前台使用是否受影响。

## 用户角色

系统管理员维护推荐，首页用户选择推荐并使用提示词。沿用既有管理权限和路由。

## 功能范围

- 所有推荐选择弹窗允许重复添加同一目标；对话框功能子类型允许多个推荐。
- 对话框推荐维护 `prompts: { title, content, icon }[]`，支持新增、修改、删除与编辑回填。
- 检查推荐记录 ID 与智能体 ID 的使用区别，修复重复推荐造成的智能体下拉重复。
- 首页优先使用选中推荐的有效提示词，未配置时保留智能体引导问题。已向用户提供可选范围问题，暂按此默认实施。
- 不涉及后端、移动端、发布部署或新增独立提示词管理菜单。

## 字段和异常

提示词内容不能为空白；标题、图标可选，空标题显示内容。无提示词时提交空数组以支持清空，兼容列表返回 `null` 或缺失字段。提交失败保留输入，保存中防止重复提交。

## 待验证

测试环境新增接口是否也接受 `prompts`，以及管理列表和前台列表能否返回保存后的数组。
